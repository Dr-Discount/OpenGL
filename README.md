Introduction
  This is a real-time rendering and editing software that uses OpenGL built in c++. It allows the placement
and use of object in the editor and allow them to be texture using outside files.

Features
 - Uses vertex and fragemnt shaders
 - Uses Phong lighting
 - can edit and change the obj at anytime (never got it working)
 - has a skybax that can be changes to whatever you need.

Installation
  requires SDL3 and glm. please build in Visual Studio.

Usage
  and be used to place and edit object in a 3d space.
